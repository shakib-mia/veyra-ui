# Accordion

Description and usage examples for the `Accordion` component.

## Import

```tsx
import { Accordion } from "veyra-ui";
```

## Basic usage

```tsx
<Accordion>
  <Accordion.Item title="Section 1">Content 1</Accordion.Item>
  <Accordion.Item title="Section 2">Content 2</Accordion.Item>
</Accordion>
```
