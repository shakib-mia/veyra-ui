# Contributing

Thanks for wanting to contribute! The repo uses Vite and TypeScript.

Basic workflow:

1. Fork the repository and create a branch.
2. Run `npm install` and `npm run dev` to test locally.
3. Add tests where relevant and follow the existing component style.
4. Open a PR with a clear description and screenshots where appropriate.

Code style: follow existing patterns in `src/components` and prefer small, focused changes.
