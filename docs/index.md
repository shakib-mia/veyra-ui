# Veyra UI Documentation

Veyra UI is a TypeScript-first React library for application interfaces. Components share CSS variables, predictable controlled APIs, and composable building blocks.

## Start here

1. [Getting Started](getting-started.md) covers installation, styles, TypeScript, and the first component.
2. [Components](components/index.md) is the catalog and links to the full API reference.
3. [Theming](theming.md) explains design tokens, dark mode, and custom CSS.

- Getting started: [Getting Started](getting-started.md)
- Components: [Components Overview](components/index.md)
- Theming: [Theming & CSS](theming.md)
- Contributing: [Contributing](contributing.md)

## Package facts

- Install: `npm install veyra-ui`
- React: `^18.0.0 || ^19.0.0`
- Peer dependency: `react-select` for `Select`
- Styles: `veyra-ui/styles.css`
- Source: `src/components`
